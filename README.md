🛒 ECom - E-Commerce Application (QA / Testing Focused Project)

📌 Overview

ECom is a full-stack e-commerce application developed and tested to demonstrate real-world
Software Testing and Quality Assurance practices

This project highlights my ability to:

* Understand business requirements
* Design and execute test scenarios
* Perform functional testing
* Identify defects and document them clearly

---

🎯 Objective

To simulate a real-world QA environment by applying:

* Manual Testing
* Test Case Design
* Defect Tracking
* End-to-End User Flow Validation

---

🚀 Application Features

👤 User Module

* User Registration & Login
* Product Browsing & Search
* Add to Cart / Remove from Cart
* Checkout & Order Placement

🛠️ Admin Module

* Product Management (Add / Update / Delete)
* Order Management

---

🧪 Testing Scope

✔️ Functional Testing

* Login & Authentication validation
* Product search and filtering
* Cart functionality
* Order placement workflow

✔️ End-to-End Testing

* Complete user journey from login → purchase

✔️ Regression Testing

* Ensured existing features work after updates
